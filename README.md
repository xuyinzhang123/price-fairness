# 冤种指数 · Price Fairness

**钱都花了，看看自己冤不冤。**

一个从出差消费和朋友圈讨论中长出来的开源微信小程序：晒真实消费，聊地域价差，让“当地人心里有数”逐渐变成“外地人也有参考”。

## 为什么做这个项目

我经常出差。在外地吃完饭，看到账单，有时会惊讶：“这么多东西才这么点钱？在我家乡，可能要贵很多。”我会拍照发朋友圈，感慨“感觉赚大了”，朋友们也会聊起自己当地的价格。

刷旅游视频时，我又经常看到另一种场景：游客分享一顿当地特色菜，评论区却有当地人说“这个价格贵了”。比如安徽的臭鳜鱼、东北的锅包肉，当地人往往知道普通餐馆的大致价位，第一次来的游客却缺少参照。

于是有了「冤种指数」：先记录一次消费后的心情——**感觉赚了，还是怀疑冤了？你们那边，这些得多少钱？** 再通过大家自愿分享的真实报价，尝试减少这样的信息差。

## 现在能做什么，未来想做什么

- **现在：**拍照或手动记录名称、金额和地点，生成晒价卡；选择“感觉赚了 / 怀疑冤了 / 朋友评理”，也可以公开同城、补报价和留言。
- **已有的参考能力：**微信云开发版可根据近期同城同名称的有效用户报价计算价格百分位；至少需要 5 位其他用户的有效样本。个人感受与样本评分分开展示。
- **仍需解决：**同名不等于可比。份量、规格、餐馆类型和消费条件尚未充分核实；当前分位不代表全城行情，不能据此判断“宰客”。酒店和整桌总价等条件不足的记录不评分。
- **长期愿景：**从当地特色消费等具体场景开始，积累有时间、地点、份量与来源的可比样本，逐步形成细分的价格区间和消费价格指数。这是探索方向，尚未完成。

项目处于早期体验阶段，AI 图片识别和外部价格搜索尚未在云版启用。欢迎体验、反馈和共建；不提供实时全网比价，也不把价格高低当作商家服务质量的评价。

## 在线体验

**[打开网页演示 →](https://xuyinzhang123.github.io/price-fairness/)**

无需登录，可上传本机照片、使用虚构示例、生成消费卡片和模拟补价。照片不会上传，示例不代表市场行情，本机补价不会进入真实数据库。网页指数仅演示算法；云开发版根据真实有效用户样本计算。

网页源码在 demo/，由 GitHub Pages 托管。网页已支持三种情绪选项、精简分享卡片和项目缘起；它仍是独立的本机演示，不连接微信真实报价库，也不包含小程序的全部功能。

微信版目前为受限体验版本，并非人人可直接使用的正式上线服务。开发者可按下方指引部署自己的环境。

## 已完成

- 拍照 / 相册 / 手动输入，商品或服务名称可修改；支持餐饮、酒店等消费记录。
- 城市选择与记忆；店名、消费场景、附近地标选填。
- 三种消费分享卡片样式，保存到相册；在结果页选择“感觉赚了 / 怀疑冤了 / 朋友评理”，个人感受与真实样本指数分开展示。
- 用户主动选择公开同城展示；按城市和名称搜索。
- 原帖下补报价和留言；微信身份关联云端记录。
- 上传前缩图、压缩与 JPEG 备用转换，云模式照片单独上传云存储，发布请求只传文件编号。

## 状态必须区分

| 模式 | 数据存储 | AI | 指数 |
| --- | --- | --- | --- |
| 本机预览 | 微信设备缓存 | 关闭 | 不自动评分 |
| 微信云开发 | 云数据库 + 云存储 | 关闭 | 已接真实用户样本的百分位评分，至少5位其他用户；酒店等条件不足不评分 |
| 独立 Node 开发后台 | SQLite | 提供可选适配器，未完成真实效果验证 | 有百分位算法、筛样本与缓存的测试实现 |

云开发版已进行小范围真机试用，包括多人晒价、搜索和补报价；不同设备、图片格式和网络条件还需继续验证。源码中的测试属于模拟和本地验证，不能替代真实云端权限与微信平台审核。

## 本机预览

1. 使用微信开发者工具导入本仓库根目录。
2. 换成自己的 AppID；touristappid 只是占位，部分功能需正式 AppID。
3. 默认 miniprogram/config.js 中 cloudEnv 和 apiBaseUrl 均为空，只使用设备缓存。
4. 编译后可体验手动晒价和卡片。跨手机数据同步需部署自己的后台。

## 微信云开发

按 [云开发部署指引](docs/cloud-setup.md) 创建自己的环境、集合并部署 priceApi。
**必须配置自己的 AppID 和环境，不要连接项目作者的服务。**
云版不需要 AI API 密钥。云服务可能产生存储、网络和函数调用费用，以服务平台为准。

## 独立后台（可选）

需要 Node.js 24 或更新版本，使用内置 SQLite：

    node server/index.js

默认监听 127.0.0.1:8787，数据写入 server/data/prices.sqlite。
需要环境配置时复制 .env.example 为 .env，保持 EXTERNAL_AI_ENABLED=false；启动：

    node --env-file=.env server/index.js

外部 AI 还需要自行配置服务商和额度，开源代码不提供免费 API。独立后台尚无完整身份与滥用防护，仅用于本地开发；公网使用前需完善权限、HTTPS 和部署方案。它与云数据库是两套实现，数据不会自动互通。
