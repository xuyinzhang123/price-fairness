# [Scoring] 云开发版真实样本与百分位指数

## 当前情况

基础实现已接入：云端读取公开晒价和结构化补报价，筛选近期同城同名称、同价格类型与场景的样本，按可信用户去重并排除报价主体；至少 5 位其他用户后计算中位排名百分位。留言不计入样本，酒店与整桌总价等条件不足不评分。

已有自动化模拟检查，但没有完成足量真实可比样本下的多手机验收。同名称不代表规格、份量或商家类型相同，结果不等于当地市场价格标准。

## 后续验收

- [x] 读取晒价和结构化补报价，留言不计入样本
- [x] 排除报价主体，时间窗与按用户去重生效
- [x] 样本不足不评分，接口提供有效样本数、时间和参考报价
- [x] 百分位为低于当前价的数量加一半同价数量，再除总数
- [ ] 足量真实样本下，验证不同查看者看到同一报价的结果一致
- [ ] 对齐云端与独立 Node 的样本筛选边界并验证结果
- [ ] 完善份量、规格和场景可比条件，以及异常报价与截断提示
