# 冤种指数：项目介绍与发布文案

## 一句话介绍

晒真实消费，聊地域价差，让“当地人心里有数”逐渐变成“外地人也有参考”。

## 项目缘起（作者第一人称草稿）

我经常出差。在外地吃完饭，看到账单，有时候会惊讶：“这么多东西才这么点钱？在我家乡，可能要贵很多。”

我会拍照发朋友圈，感慨“感觉赚大了”，朋友也会聊起自己当地的价格。分享的不只是一顿饭，还有不同城市的生活差异，以及花钱之后想被人回应的那一点心情。

刷旅游视频时，我经常看到另一种情况：游客分享当地特色菜，评论区却有当地人说“贵了”。比如安徽的臭鳜鱼、东北的锅包肉，当地人心里往往有个价位，游客却不知道。

所以我做了「冤种指数」。你可以记录照片、金额和地点，表达“感觉赚了”或“怀疑冤了”，生成晒价卡，问问别人：“你们那边，这些得多少钱？”

我希望随着真实消费记录积累，逐步整理同地区、相近时间和可比条件下的价格参考。样本足够时，再尝试给出价格位置、趣味称号，甚至细分的价格指数；条件不足时就不硬评分。

目前已有小范围试用的微信小程序和公开网页演示，代码已开源。它还不完善，欢迎体验反馈、分享当地经验，或者一起参与开发。

## 开发者社区发布稿

标题：经常出差的我，因为一句“你们那边多少钱”，做了一个叫「冤种指数」的小程序

正文使用上面的项目缘起，随后补充：

- 网页演示：https://xuyinzhang123.github.io/price-fairness/
- 开源仓库：https://github.com/xuyinzhang123/price-fairness
- 网页使用虚构样本、本机处理照片，不与真实报价库互通；微信版目前为受限体验版本。
- 希望获得的帮助：手机体验反馈、当地特色菜的可比条件设计、记录管理与内容治理。

结尾提问：你所在的地方，有哪道特色菜，是游客不知道价、当地人心里有数的？

## 配图与演示准备

尚待补充，不能把这些材料当作已经制作完成：

1. 一张“感觉赚了”和一张“怀疑冤了”的卡片，使用有权公开的照片，标注个人感受。
2. 一段约 30 秒的手机演示，展示照片、确认、卡片三步，不暴露用户身份。
3. 有样本与无样本两种结果的说明；演示数据明确标注，不伪装真实行情。

## 传播与反馈记录

先发布创作缘起和少量真实消费故事，按社区规则选择相关栏目，不刷屏、不刷赞，不擅自使用他人的视频、评论或照片。

重点记录陌生人是否理解用途、提出当地报价、尝试体验、反馈问题或愿意贡献。曝光量与 Star 仅作辅助，不把它们当作真实使用或数据可靠性的证明。
